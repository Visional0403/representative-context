# Datasets

[docs/datasets.md](../docs/datasets.md) lists each dataset's download source,
complete evaluation split and preparation commands. The fixed UAVid training
tiles are generated by `python scripts/prepare_uavid_crops.py`.

Obtain UAVid from its official distribution and arrange its original
splits as follows:

```text
datasets/UAVid/
  train/seq*/Images/*.png
  train/seq*/Labels/*.png
  val/seq*/Images/*.png
  val/seq*/Labels/*.png
```

The evaluation reader sorts complete image paths and pairs labels by
sequence and filename. Original validation images are normalized without
resizing or augmentation. Eight-class RGB labels follow the official
color map in `src/representative_context/data/uavid.py`.

Dataset files are excluded from Git. Respect the data provider's terms.
`--data-root` can select another installation of this same directory tree.

Additional complete prediction splits use these paths:

```text
datasets/kvasir_seg/images/*
datasets/kvasir_seg/masks/*
datasets/chameleon/Imgs/*
datasets/chameleon/GT/*
datasets/columbia/4cam_splc/*.tif
datasets/columbia/4cam_splc/edgemask/*_edgemask.jpg
datasets/levir_cd/test.zip
datasets/oam_tcd/test.parquet
datasets/nyuv2/nyu_depth_v2_labeled.mat
datasets/nyuv2/splits.mat
```

Kvasir-SEG uses the 100-image test split distributed for Polyp-PVT.
LEVIR-CD's archive contains `A/`, `B/` and `label/` for all 128 test pairs.
OAM-TCD uses the complete 439-image CC-BY test shard. NYUv2 uses the
official 654 test indices from `splits.mat`. Per-task processing and
evaluation units are described in [docs/prediction.md](../docs/prediction.md).

Motion, fusion and restoration data:

```text
datasets/sintel/MPI-Sintel-training_images.zip
datasets/sintel/MPI-Sintel-training_extras.zip
datasets/cave/Test_CAVE.h5
datasets/quickbird/test_qb_multiExm1.h5
datasets/div2k_hr/*.png
datasets/gopro_test/**/input.lmdb/data.mdb
datasets/gopro_test/**/target.lmdb/data.mdb
```

Sintel evaluation uses all 1041 labeled Final image pairs. CAVE contains
the authors' eleven test cubes. QuickBird uses all twenty reduced-
resolution reference examples from PanCollection. DIV2K uses all one
hundred original validation HR images. GoPro uses the NAFNet-distributed
LMDB representation of all 1111 official test pairs.

Forensics, height, counting and multiview data:

```text
datasets/imd2020/**/*_mask.png
datasets/imd2020/**/*.[jpg|png|JPG]
datasets/gamus/images/test/*_RGB.h5
datasets/gamus/heights/test/*_AGL.h5
datasets/fsc147/annotations/Train_Test_Val_FSC_147.json
datasets/fsc147/annotations/annotation_FSC147_384.json
datasets/fsc147/images_384_VarV2/*.jpg
datasets/tum/rgbd_dataset_freiburg1_desk/rgb/*
datasets/tum/rgbd_dataset_freiburg1_desk/depth/*
datasets/tum/rgbd_dataset_freiburg1_desk/{rgb,depth,groundtruth}.txt
```

The GAMUS and TUM sample identities are fixed in the corresponding
configuration folders. FSC147 uses its complete 1190-image official test
list and the supplied exemplar annotations. TUM evaluation covers the
complete fr1/desk sequence with valid timestamp matches.

Cityscapes retains its standard `leftImg8bit/` and `gtFine/` trees under
`datasets/Cityscapes/`. Twins/UAVid training uses the 5600 fixed crops
under `datasets/UAVidCrops/train/seq*/{Images,Labels}/`, while validation
uses original images under `datasets/UAVid/val/`.
